# jobs/

One subfolder per application, e.g. `jobs/acme-corp/`, containing:

- `job-description.md` — the full pasted JD
- `analysis.md` — output of the `analyze-job` prompt
- `targeted-resume.md` — output of the `tailor-resume` prompt
- `ats-review.md` — output of the `ats-review` prompt

See the root [README.md](../README.md) for the full workflow.
