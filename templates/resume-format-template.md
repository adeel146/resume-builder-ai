# Resume Format Template (structure reference only)

> Source: "Shahroz Sarfraz SQA Engineer" resume — used ONLY as a layout/structure reference.
> Do NOT reuse any of its content, metrics, or wording. All content must come from `master/` files.

## Layout rules

1. **Header**
   - Full name, centered/bold, large.
   - One-line professional summary/tagline directly under the name (role + years of experience + 3-5 core strengths).
   - Contact line with icons: Email | Phone | GitHub (or portfolio) | LinkedIn — all on one line.

2. **EDUCATION** (section header, bold, small-caps or all-caps, underlined/ruled)
   - Institution name (bold) — right-aligned dates on the same line.
   - Degree/program name — right-aligned CGPA/GPA if available on the same line.

3. **WORK EXPERIENCE** (section header)
   - For each employer: **Role title, Company name** — right-aligned dates on the same line.
   - If a role spans multiple distinct projects/clients, break it into **Project: <Project Name>** sub-headings, each followed by its own bullet list of achievements (bullets use quantified, result-oriented phrasing: action verb + what was done + quantified outcome).
   - Bullets are concise (1-2 lines), start with strong action verbs, and end with a measurable result where possible.

4. **ACADEMIC PROJECTS** (optional section, only if non-work projects exist worth listing)
   - Project name (bold).
   - 1-2 sentence narrative description with quantified impact.
   - Optional "Roles and Responsibilities" bullet sub-list.

5. **TECHNICAL SKILLS** (section header)
   - Single-line category rows: **Category label (bold):** comma-separated list of skills/tools.
   - Categories are grouped by purpose (e.g., scripting languages, testing tools, API tools, platform skills, version control, bug tracking) rather than generic "hard/soft skills."

6. **CERTIFICATES** (section header)
   - Bullet list, each: certificate name (bold) — issuing platform/organization in parentheses.

## Visual/formatting notes

- Clean horizontal rule under each section header.
- Bold used for: name, section headers, role/company/project titles, skill category labels, certificate names.
- Bullets use a consistent bullet character (•) with hanging indent.
- Dates right-aligned opposite the role/institution/company name — compact one-line header per entry rather than a separate line for dates.
- No separate "Summary" section — the one-line tagline under the name serves this purpose, keeping the resume to 1-2 pages.
